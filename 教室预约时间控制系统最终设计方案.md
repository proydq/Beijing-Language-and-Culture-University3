一、核心业务逻辑

1.1 时间限制规则体系

1.1.1 基础限制规则

1. 提前预约天数限制（用户-教室权限配置）
   - 限制可预约的未来日期范围
   - 计算公式：当前日期 + 提前预约天数
   - 示例：今天3月1日，提前预约16天，可预约至3月16日
2. 连续预约天数限制（教室配置）
   - 限制单次预约的时间跨度
   - 计算公式：结束日期 - 开始日期 + 1 ≤ 连续预约天数
   - 示例：连续预约3天，可选择3月1日-3月3日
3. 教学周限制（新增）
   - 只能预约当前教学周及之后的时间
   - 不能预约非教学周期间
   - 不能跨学期预约

1.1.2 综合限制逻辑

最终可预约时间 = MIN(
提前预约天数限制的日期,
当前学期最后一天,
教学周范围内的日期
)

1.2 时间计算示例

假设：
- 当前日期：2025年4月28日（第9周周一）
- 提前预约天数：7天
- 连续预约天数：3天

则：
- 可预约日期范围：2025-04-28 至 2025-05-05
- 单次预约最大跨度：3天
- 实际可选教学周：第9周、第10周（部分）

三、服务层实现设计

3.1 核心服务方法

@Service
public class RoomBookingTimeService {

      /**
       * 获取教室预约时间配置
       */
      public BookingTimeConfigDTO getBookingTimeConfig(String roomId) {
          // 1. 获取当前用户的权限配置
          BookingPersonnelPermission permission = getPermission(userId, roomId);

          // 2. 获取教室的连续预约设置
          ContinuousBookingSetting setting = getSetting(roomId);

          // 3. 获取当前教学周
          SchoolCalendar2 currentWeek = getCurrentWeek();

          // 4. 计算可预约日期范围
          DateRange availableRange = calculateAvailableDateRange(
              permission.getAdvanceBookingDays(),
              currentWeek,
              getSemesterEndDate()
          );

          // 5. 构建返回数据
          return buildConfigDTO(availableRange, permission, setting, currentWeek);
      }

      /**
       * 验证预约时间合法性
       */
      public ValidationResult validateBookingTime(
          String roomId,
          LocalDateTime startTime,
          LocalDateTime endTime
      ) {
          ValidationResult result = new ValidationResult();

          // 1. 验证是否晚于当前时间
          if (startTime.isBefore(LocalDateTime.now())) {
              result.addError("START_TIME_PAST", "开始时间不能早于当前时间");
          }

          // 2. 验证提前预约天数
          int advanceDays = getAdvanceBookingDays(userId, roomId);
          LocalDate maxDate = LocalDate.now().plusDays(advanceDays);
          if (endTime.toLocalDate().isAfter(maxDate)) {
              result.addError("EXCEED_ADVANCE_DAYS",
                  String.format("超出允许的提前预约天数（%d天）", advanceDays));
          }

          // 3. 验证连续预约天数
          long duration = ChronoUnit.DAYS.between(
              startTime.toLocalDate(),
              endTime.toLocalDate()
          ) + 1;
          int maxContinuousDays = getContinuousBookingDays(roomId);
          if (duration > maxContinuousDays) {
              result.addError("EXCEED_CONTINUOUS_DAYS",
                  String.format("超出允许的连续预约天数（%d天）", maxContinuousDays));
          }

          // 4. 验证是否在教学周内
          if (!isInTeachingWeek(startTime) || !isInTeachingWeek(endTime)) {
              result.addError("NOT_IN_TEACHING_WEEK", "预约时间必须在教学周内");
          }

          // 5. 验证时间冲突
          if (hasTimeConflict(roomId, startTime, endTime)) {
              result.addError("TIME_CONFLICT", "该时间段已被预约");
          }

          return result;
      }
}

3.2 工具方法

/**
* 计算可预约日期范围
  */
  private DateRange calculateAvailableDateRange(
  int advanceDays,
  SchoolCalendar2 currentWeek,
  LocalDate semesterEndDate
  ) {
  LocalDate today = LocalDate.now();
  LocalDate maxAdvanceDate = today.plusDays(advanceDays);

  // 取最小值：提前预约限制、学期结束日期
  LocalDate endDate = maxAdvanceDate.isBefore(semesterEndDate)
  ? maxAdvanceDate : semesterEndDate;

  // 如果当前不在教学周，从下一个教学周开始
  LocalDate startDate = currentWeek != null
  ? today : getNextTeachingWeekStartDate();

  return new DateRange(startDate, endDate);
  }

/**
* 获取指定日期范围内的可预约日期列表
  */
  private List<BookableDate> getBookableDates(
  LocalDate startDate,
  LocalDate endDate
  ) {
  List<BookableDate> dates = new ArrayList<>();
  LocalDate current = startDate;

  while (!current.isAfter(endDate)) {
  if (isInTeachingWeek(current)) {
  BookableDate bookableDate = new BookableDate();
  bookableDate.setDate(current);
  bookableDate.setWeekNumber(getWeekNumber(current));
  bookableDate.setIsToday(current.equals(LocalDate.now()));

           // 如果是今天，设置最早可预约时间
           if (bookableDate.getIsToday()) {
               bookableDate.setMinTime(LocalTime.now());
           }

           dates.add(bookableDate);
       }
       current = current.plusDays(1);
  }

  return dates;
  }

六、异常处理方案

6.1 异常场景

1. 无教学周数据
   - 提示："当前时间不在教学周内，请联系管理员"
   - 禁用预约功能
2. 无权限配置
   - 使用默认值（提前7天，连续3天）
   - 记录日志提醒配置
3. 配置冲突
   - 如：提前预约天数=0
   - 提示："预约配置异常，请联系管理员"
