# 权限系统升级实施计划

## 一、实施目标

将现有权限系统升级为企业级权限管理系统，实现：
- 规范化的权限码体系
- 动态权限配置与热更新
- 完整的审计追踪
- 可视化权限管理

### Step 2: 后端核心组件开发（第2-3周）

#### 2.1 创建权限评估器
```java
// 新建 CustomPermissionEvaluator.java
@Component
public class CustomPermissionEvaluator implements PermissionEvaluator {
    
    @Autowired
    private PermissionService permissionService;
    
    @Override
    public boolean hasPermission(Authentication auth, Object targetDomainObject, Object permission) {
        if (auth == null || permission == null) {
            return false;
        }
        
        String permCode = permission.toString();
        Collection<? extends GrantedAuthority> authorities = auth.getAuthorities();
        
        // 1. 获取用户所有权限（包含别名转换）
        Set<String> userPerms = extractPermissions(authorities);
        
        // 2. 检查是否有manage权限（隐含所有子权限）
        String domain = permCode.split(":")[0];
        String resource = permCode.split(":")[1];
        if (userPerms.contains(domain + ":" + resource + ":manage")) {
            return true;
        }
        
        // 3. 检查具体权限
        return userPerms.contains(permCode);
    }
}
```

#### 2.2 动态URL鉴权
```java
// 新建 DynamicSecurityMetadataSource.java
@Component
public class DynamicSecurityMetadataSource implements FilterInvocationSecurityMetadataSource {
    
    private Map<RequestMatcher, Collection<ConfigAttribute>> requestMap = new ConcurrentHashMap<>();
    
    @PostConstruct
    public void loadResourceDefine() {
        // 从数据库加载URL-权限映射
        List<PermissionUrl> urlPerms = permissionUrlRepository.findAllByStatus(1);
        for (PermissionUrl up : urlPerms) {
            requestMap.put(
                new AntPathRequestMatcher(up.getUrlPattern(), up.getHttpMethod()),
                SecurityConfig.createList(up.getPermCode())
            );
        }
    }
    
    public void refresh() {
        requestMap.clear();
        loadResourceDefine();
    }
}
```

#### 2.3 审计日志AOP
```java
// 新建 AuditLogAspect.java
@Aspect
@Component
public class AuditLogAspect {
    
    @Around("@annotation(preAuthorize)")
    public Object audit(ProceedingJoinPoint joinPoint, PreAuthorize preAuthorize) throws Throwable {
        long startTime = System.currentTimeMillis();
        AuditLog log = new AuditLog();
        
        try {
            // 记录请求信息
            log.setUserId(SecurityUtil.getCurrentUserId());
            log.setAction(joinPoint.getSignature().getName());
            log.setPermCode(extractPermCode(preAuthorize.value()));
            log.setRequestTime(new Date());
            
            // 执行方法
            Object result = joinPoint.proceed();
            
            log.setSuccess(true);
            return result;
            
        } catch (Exception e) {
            log.setSuccess(false);
            log.setErrorMsg(e.getMessage());
            throw e;
        } finally {
            log.setDuration(System.currentTimeMillis() - startTime);
            auditLogService.save(log);
        }
    }
}
```

### Step 3: 前端权限升级（第4周）

#### 3.1 升级权限Store
```javascript
// src/stores/auth.js
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useAuthStore = defineStore('auth', () => {
  const permissions = ref([])
  const permissionMap = ref({}) // 新旧权限码映射
  
  // 统一权限检查方法（支持新旧权限码）
  const hasPermission = (code) => {
    // 1. 直接检查
    if (permissions.value.includes(code)) return true
    
    // 2. 检查别名
    const newCode = permissionMap.value[code]
    if (newCode && permissions.value.includes(newCode)) return true
    
    // 3. 检查manage权限
    if (code.includes(':')) {
      const [domain, resource] = code.split(':')
      const manageCode = `${domain}:${resource}:manage`
      if (permissions.value.includes(manageCode)) return true
    }
    
    return false
  }
  
  return {
    permissions,
    hasPermission,
    hasAny: (codes) => codes.some(hasPermission),
    hasAll: (codes) => codes.every(hasPermission)
  }
})
```

#### 3.2 增强v-perm指令
```javascript
// src/directives/permission.js
export const permission = {
  mounted(el, binding) {
    const { value, arg = 'any', modifiers } = binding
    const store = useAuthStore()
    
    const codes = Array.isArray(value) ? value : [value]
    let hasPermission = false
    
    if (arg === 'all') {
      hasPermission = store.hasAll(codes)
    } else if (arg === 'not') {
      hasPermission = !store.hasAny(codes)
    } else {
      hasPermission = store.hasAny(codes)
    }
    
    if (!hasPermission) {
      if (modifiers.disable) {
        el.disabled = true
        el.classList.add('is-disabled')
      } else {
        el.remove()
      }
    }
  }
}

// 使用示例

// v-perm:all="['building:room:create', 'building:room:update']"
// v-perm.disable="'building:room:delete'"
```

#### 5.2 迁移脚本
```sql
-- 更新所有权限的perm_code字段
UPDATE sys_permission p
JOIN sys_permission_alias a ON p.code = a.old_code
SET p.perm_code = a.new_code
WHERE p.perm_code IS NULL;

-- 生成URL权限映射
```
