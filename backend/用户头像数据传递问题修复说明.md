# 用户头像数据传递问题修复说明

## 问题诊断

通过分析发现，数据库中有 avatarUrl 数据，但前端 userInfo 中没有的根本原因是：

**登录接口的 LoginResponse DTO 缺少 avatarUrl、email 等扩展字段**

## 问题分析过程

1. **实体类检查** ✅ 正常
   - `SysUser.java` 中正确定义了 `@Column(name = "avatar_url")` 字段
   
2. **数据库字段映射** ✅ 正常
   - 实体类与数据库字段映射正确
   
3. **Service 层查询** ✅ 正常
   - `SysUserServiceImpl.findById()` 方法能正确查询包含 avatarUrl 的完整数据
   
4. **登录接口问题** ❌ 发现问题
   - `LoginResponse.java` 中缺少 avatarUrl、email 等字段
   - `AuthenticationServiceImpl.login()` 方法没有设置这些字段

## 修复内容

### 1. 扩展 LoginResponse DTO

**文件**：`backend/src/main/java/com/proshine/system/dto/LoginResponse.java`

```java
// 新增字段
private String avatarUrl;
private String email;
private String phone;
private String departmentName;
private String positionName;
```

### 2. 修改登录服务实现

**文件**：`backend/src/main/java/com/proshine/system/service/impl/AuthenticationServiceImpl.java`

在 login 方法中添加字段设置：

```java
// 构建完整的登录响应
LoginResponse response = new LoginResponse(token, user.getId(), user.getUsername(), 
        user.getRealName(), user.getCustomerId());
response.setAvatarUrl(user.getAvatarUrl());
response.setEmail(user.getEmail());
response.setPhone(user.getPhone());
response.setDepartmentName(user.getDepartmentName());
response.setPositionName(user.getPositionName());
response.setPermissions(permissionCodes);
response.setPermissionDetails(permissionDetails);
response.setRoles(roleCodes);
response.setPermissionTree(permissionTree);
```

### 3. 添加测试数据

**文件**：`backend/src/main/resources/sql/add_test_avatar.sql`

为测试用户添加头像和邮箱数据：

```sql
UPDATE sys_user 
SET avatar_url = 'https://cube.elemecdn.com/3/7c/3ea6beec64369c2642b92c6726f1epng.png',
    email = 'testuser@example.com'
WHERE username = 'testuser' AND customer_id = 'demo';
```

## 修复效果

修复后，用户登录时会获得完整的用户信息，包括：

1. **基本信息**：
   - username: 用户名
   - realName: 真实姓名
   - customerId: 客户域ID

2. **扩展信息**：
   - avatarUrl: 头像URL
   - email: 邮箱
   - phone: 电话
   - departmentName: 部门名称
   - positionName: 职位名称

3. **权限信息**：
   - permissions: 权限编码列表
   - roles: 角色列表
   - permissionTree: 权限树

## 测试方法

1. **重启后端服务**
2. **执行 SQL 脚本**：运行 `add_test_avatar.sql` 为测试用户添加头像数据
3. **重新登录**：清除前端缓存，重新登录
4. **检查数据**：
   ```javascript
   // 在控制台检查
   const userStore = document.querySelector('#app').__vue_app__.config.globalProperties.$pinia._s.get('user')
   console.log('头像URL:', userStore.userInfo.avatarUrl)
   console.log('邮箱:', userStore.userInfo.email)
   ```

## 影响范围

1. **登录接口**：`/authentication/login` 返回数据更完整
2. **前端 userInfo**：包含完整的用户信息
3. **头像显示**：如果数据库中有头像URL，前端会正确显示
4. **用户详情接口**：`/system/user/current` 也会返回完整信息

## 注意事项

1. **数据完整性**：确保数据库中用户记录的 avatar_url 字段有值
2. **图片链接**：确保头像URL是可访问的
3. **前端缓存**：修改后需要清除前端本地存储缓存
4. **向后兼容**：新增字段不会影响现有功能
