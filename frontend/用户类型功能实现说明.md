# 用户类型功能实现说明

## 实现内容

已在用户信息管理模块的新增用户和编辑用户弹出框中添加了用户类型字段。

### 修改的文件

1. **src/api/user.js**
   - 添加了 `getUserTypes()` 方法，用于获取用户类型列表
   - API 端点：`/system/user/userTypes`

2. **src/composables/useUserManagement.js**
   - 添加了用户类型相关状态：
     - `userTypes` - 用户类型列表
     - `userTypesLoading` - 加载状态
   - 添加了 `fetchUserTypes()` 方法获取用户类型
   - 在表单数据中添加了 `userType` 字段，默认值为"教师"
   - 在表单验证规则中添加了用户类型的必填验证
   - 在新增和编辑时自动调用 `fetchUserTypes()` 获取类型列表
   - 保存用户时包含 `userType` 字段

3. **src/views/UserManagement.vue**
   - 在用户表单中添加了用户类型选择器
   - 位置：与无感考勤编号在同一行，各占12列

## 功能特性

1. **默认值处理**
   - 新增用户时，用户类型默认为"教师"
   - 编辑用户时，显示用户当前的类型，如果没有则默认为"教师"

2. **错误处理**
   - 如果后端API调用失败，会使用默认的用户类型列表：["教师", "学生"]
   - 确保用户界面始终可用

3. **表单验证**
   - 用户类型为必填字段
   - 使用下拉选择器，避免输入错误

## 测试步骤

1. **新增用户测试**
   - 点击"新增用户"按钮
   - 检查表单中是否出现"用户类型"下拉框
   - 验证默认值是否为"教师"
   - 选择不同的用户类型并保存

2. **编辑用户测试**
   - 点击某个用户的"编辑"按钮
   - 检查用户类型是否正确显示
   - 修改用户类型并保存

3. **验证测试**
   - 尝试不选择用户类型直接保存
   - 应该显示验证错误提示

## 后端接口要求

后端需要提供以下支持：

1. **GET /system/user/userTypes**
   - 返回用户类型列表
   - 预期格式：
   ```json
   {
     "code": 200,
     "data": [
       { "value": "教师", "label": "教师" },
       { "value": "学生", "label": "学生" }
     ]
   }
   ```

2. **用户实体**
   - 需要包含 `userType` 字段
   - 在创建和更新用户时接收并保存该字段

## 注意事项

- 用户类型数据会在打开新增/编辑对话框时自动加载
- 如果后端接口尚未实现，前端会使用默认的类型列表，不影响功能使用
- 保存用户时会将用户类型一并提交到后端
