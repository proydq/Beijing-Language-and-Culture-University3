# 前端预约时间控制集成说明

## 概述

前端已经成功集成了新的预约时间控制系统，现在时间选择功能将使用后端的实时数据和约束进行验证。

## 更新内容

### 1. 新增API接口文件
- **文件**: `src/api/bookingTimeControl.js`
- **功能**: 
  - `getBookingTimeConfig(roomId)` - 获取教室预约时间配置
  - `getCurrentTimeInfo()` - 获取当前时间信息  
  - `validateBookingTime(data)` - 验证预约时间合法性

### 2. 更新TimeSelectorDialog组件
- **文件**: `src/components/RoomBooking/Booking/TimeSelectorDialog.vue`
- **主要更新**:
  - 集成新的预约时间配置API
  - 显示服务器当前时间和教学周信息
  - 显示预约限制（提前预约天数、连续预约设置）
  - 实时时间验证功能
  - 教学周约束检查
  - 预约冲突检测

### 3. 新功能特性

#### 预约信息显示
- 当前服务器时间
- 当前教学周信息
- 预约限制说明（提前天数、连续预约限制）

#### 教学周管理
- 使用后端真实教学周数据
- 显示每周可预约天数
- 禁用不可预约的教学周

#### 实时验证
- 选择时间时自动检查约束
- 最终保存前完整验证
- 详细的错误提示和建议

#### 约束检查
- 当前时间约束
- 提前预约天数限制
- 连续预约天数限制
- 教学周时间范围
- 时间冲突检测

## 使用方式

### 预约流程
1. 用户点击"立即预约"按钮
2. 打开预约对话框，选择时间
3. 时间选择器自动加载教室的预约配置
4. 显示当前时间、教学周等信息
5. 用户选择时间时进行实时验证
6. 保存前进行最终完整验证
7. 验证通过后返回选择结果

### API调用链
```
TimeSelectorDialog 
  ├── loadBookingTimeConfig() → /api/room-booking/booking-time-config
  ├── toggleSelect() → validateBookingTime() → /api/room-booking/validate-booking-time  
  └── save() → validateBookingTime() → /api/room-booking/validate-booking-time
```

## 错误处理

### 验证失败处理
- 显示详细错误消息
- 提供建议操作
- 阻止无效时间选择

### API故障降级
- 如果新API不可用，自动降级到旧的getSchoolWeeks API
- 保证基本功能可用

## 测试建议

1. **基础功能测试**
   - 打开时间选择对话框
   - 检查是否显示预约配置信息
   - 验证教学周数据是否正确加载

2. **约束测试**
   - 尝试选择过早的时间（应被阻止）
   - 尝试选择超出提前预约天数的时间
   - 尝试选择超出连续预约天数的时间范围
   - 尝试选择非教学周时间

3. **验证测试**
   - 选择有效时间，检查是否可以保存
   - 选择无效时间，检查是否显示错误提示
   - 检查错误消息是否有用户友好的建议

4. **降级测试**
   - 暂时关闭新API，测试是否自动降级
   - 检查基本功能是否仍然可用
