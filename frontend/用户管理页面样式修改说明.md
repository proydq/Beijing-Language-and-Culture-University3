# 用户管理页面样式修改说明

## 修改概述

根据《登录与系统选择页面样式风格指南》和《前端样式与风格指南》的要求，对用户管理页面的样式进行了全面重构，使其符合统一的设计规范。

## 主要修改内容

### 1. 样式语言升级
- 将原有的 CSS 样式改为 SCSS
- 使用 SCSS 的变量、嵌套、函数等特性
- 添加 `lang="scss"` 属性

### 2. 设计规范统一

#### 颜色系统
使用风格指南中定义的颜色变量：
- **主色调**：`$primary-color: #409EFF`
- **文字颜色**：
  - 主要文字：`$text-primary: #303133`
  - 常规文字：`$text-regular: #606266`
  - 次要文字：`$text-secondary: #909399`
- **背景颜色**：
  - 页面背景：`$bg-page: #F0F2F5`
  - 白色背景：`$bg-white: #FFFFFF`
  - 次级背景：`$bg-color: #F5F7FA`
- **边框颜色**：使用 `$border-light`、`$border-lighter` 等

#### 字体规范
- 基础字号：`$font-size-base: 14px`
- 标题字号：`$font-size-lg: 18px`
- 统一字重：标题 500，正文 normal

#### 间距系统
- 统一使用间距变量：`$spacing-sm`、`$spacing-md`、`$spacing-lg` 等
- 保持组件间距的一致性

### 3. 布局优化

#### 头部导航
- 高度统一为 60px
- 背景改为白色，底部添加边框
- Logo 尺寸调整为 32px × 32px
- 移除渐变背景，采用扁平化设计

#### 侧边栏
- 宽度调整为 240px（符合规范）
- 添加自定义滚动条样式
- 优化树形节点的间距和颜色

#### 主内容区
- 背景色使用 `$bg-page`
- 卡片圆角统一为 4px
- 阴影使用标准的 `$box-shadow-light`

### 4. 组件样式优化

#### 表格样式
- 表头背景色使用 `$bg-color`
- 优化悬停效果
- 统一边框颜色

#### 按钮样式
- 主按钮颜色使用 `$primary-color`
- 优化悬停和点击效果
- 文本按钮添加合适的间距

#### 对话框样式
- 统一圆角为 4px
- 优化标题栏样式
- 调整内容区域的内边距

### 5. 响应式设计
添加移动端适配：
- 768px 以下屏幕的布局调整
- 侧边栏在移动端改为垂直布局
- 表单项在移动端改为垂直排列
- 按钮组自动换行

### 6. 过渡效果
- 统一过渡时长：`$transition-duration: 0.3s`
- 所有交互元素添加平滑过渡效果

## 视觉改进

1. **更现代的外观**
   - 采用扁平化设计，移除不必要的装饰元素
   - 使用更柔和的阴影效果
   - 统一的圆角处理

2. **更好的可读性**
   - 优化文字对比度
   - 合理的行高和间距
   - 清晰的信息层次

3. **更好的交互反馈**
   - 悬停效果更明显
   - 点击反馈更及时
   - 状态变化更平滑

## 注意事项

1. 所有颜色值都使用变量，方便后续主题切换
2. 保持了原有的功能不变，仅优化视觉效果
3. 兼容 Element Plus 的默认样式，仅做必要的覆盖
4. 支持响应式布局，适配不同设备

## 后续建议

1. 可以将颜色变量抽取到全局的 `variables.scss` 文件中
2. 考虑添加暗黑模式支持
3. 进一步优化移动端的交互体验
