# 用户头像和用户名显示分析方案

## 现状分析

### 1. 当前实现
- **位置**：UserManagement.vue 右上角
- **显示内容**：
  - 头像：显示的是一个图标 `<el-icon size="20"><user /></el-icon>`
  - 用户名：硬编码的"系统管理员"

### 2. 用户信息存储
项目使用 **Pinia store** (`src/stores/user.js`) 管理用户状态：

```javascript
// 存储的用户信息结构
userInfo: {
  id: '',
  username: '',
  realName: '',
  customerId: ''
}

// 计算属性
displayName: computed(() => {
  return userInfo.value.realName || userInfo.value.username || '用户'
})
```

### 3. 登录流程
1. 用户登录后，后端返回用户数据
2. 调用 `userStore.setUserData(userData)` 保存到 store
3. 同时保存到 localStorage 用于持久化

### 4. 问题分析
- **缺少头像字段**：当前 userInfo 中没有 avatarUrl 字段
- **未使用真实数据**：页面没有从 store 获取用户信息

## 修改方案

### 方案一：简单修改（仅显示用户名）

**步骤**：
1. 在 UserManagement.vue 中引入 user store
2. 使用 displayName 替换硬编码的"系统管理员"
3. 保持图标显示（暂不显示真实头像）

**优点**：
- 修改最小
- 立即可用
- 不需要后端配合

**代码示例**：
```vue
<script setup>
import { useUserStore } from '@/stores/user'

const userStore = useUserStore()
// 其他代码...
</script>

<template>
  <!-- 修改这部分 -->
  <span class="username">{{ userStore.displayName }}</span>
</template>
```

### 方案二：完整实现（包含头像）

**步骤**：

1. **扩展 user store**
   - 在 userInfo 中添加 avatarUrl 字段
   - 在 setUserData 方法中保存头像信息

2. **修改登录逻辑**
   - 确保后端返回的数据包含 avatarUrl
   - 或者在登录后调用额外的接口获取用户详情

3. **修改页面显示**
   - 判断是否有头像URL
   - 有则显示真实头像，无则显示默认图标

**代码示例**：

```javascript
// 1. 修改 stores/user.js
const userInfo = ref({
  id: '',
  username: '',
  realName: '',
  customerId: '',
  avatarUrl: ''  // 新增
})

const setUserData = (userData) => {
  // ... 其他代码
  userInfo.value = {
    id: userData.userId || userData.id || '',
    username: userData.username || '',
    realName: userData.realName || '',
    customerId: userData.customerId || '',
    avatarUrl: userData.avatarUrl || ''  // 新增
  }
  // ... 其他代码
}
```

```vue
// 2. 修改 UserManagement.vue
<template>
  <div class="header-right">
    <div class="avatar">
      <!-- 有头像显示头像，无头像显示图标 -->
      <el-avatar 
        v-if="userStore.userInfo.avatarUrl" 
        :src="userStore.userInfo.avatarUrl"
        :size="32"
      />
      <el-icon v-else size="20"><user /></el-icon>
    </div>
    <span class="username">{{ userStore.displayName }}</span>
    <!-- ... 其他代码 -->
  </div>
</template>
```

### 方案三：获取用户详情（推荐）

如果登录接口没有返回头像信息，可以：

1. **创建获取当前用户详情的 API**
```javascript
// api/user.js
export const userAPI = {
  // ... 其他方法
  
  /**
   * 获取当前登录用户信息
   */
  getCurrentUser() {
    return request.get('/api/user/current')
  }
}
```

2. **在登录成功后或页面加载时调用**
```javascript
// 在 useUserManagement.js 或 App.vue 中
onMounted(async () => {
  if (userStore.isLoggedIn) {
    try {
      const res = await userAPI.getCurrentUser()
      if (res.code === 200) {
        // 更新用户信息（包含头像）
        userStore.setUserData({
          ...userStore.userInfo,
          ...res.data
        })
      }
    } catch (error) {
      console.error('获取用户信息失败:', error)
    }
  }
})
```

## 建议实施步骤

1. **第一步**：先实现方案一，让用户名显示真实数据
2. **第二步**：与后端确认是否可以在登录接口返回头像URL
3. **第三步**：如果不能，实现获取当前用户详情的接口
4. **第四步**：完整实现头像显示功能

## 其他考虑

1. **默认头像**：准备一个默认头像图片，当用户没有上传头像时使用
2. **头像加载失败**：处理头像URL无效的情况
3. **全局应用**：考虑创建一个全局的用户信息组件，在所有需要显示用户信息的地方复用
4. **性能优化**：头像可以使用懒加载，避免影响页面加载速度

## 相关文件
- `/src/views/UserManagement.vue` - 需要修改的页面
- `/src/stores/user.js` - 用户状态管理
- `/src/api/user.js` - 用户相关API（可能需要新增接口）
